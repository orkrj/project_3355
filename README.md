# webshopping


## 프로젝트 소개
3팀 삼삼오오 웹 쇼핑몰 프로젝트입니다. 
개발 가이드에 맞춰 쇼핑몰을 제작하여 사용하는 목적을 가지고 있습니다.
유저 권한과 어드민 권한을 나누어 본 웹 쇼핑몰을 활용할 수 있습니다.

유저는 회원 가입, 로그인 및 로그아웃, 회원 정보 수정, 회원 탈퇴, 상품 탐색, 주문, 주문 취소, 결제를 할 수 있습니다.
어드민은 로그인 및 로그아웃, 각 도메인에 대한 CRUD 즉, 회원 관리, 카테고리 관리, 상품 관리, 주문 관리를 할 수 있습니다.
